### ✨ New

#### Rematch

Start a new match with the same players straight from a finished one.

### ⚡ Improved

#### Updates no longer interrupt you

A new version is applied when you move to another page, never in the middle of what you are doing.

### 🐛 Fixed

#### A clear message when the server cannot be reached

One warning with a retry countdown, instead of several confusing errors.

#### Notifications describe uneven matches correctly

A 2v1 is no longer shown as a 2v2.

#### Ranked ratings stay consistent after every validation

A validated match can no longer be edited or deleted: cancel it and enter it again instead, so every rating is recalculated.

- A network hiccup no longer signs you out
- Notifications show dates in your time zone and in your language

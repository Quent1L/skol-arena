### ✨ New

#### Icons for games and rank tiers

**For super admins** · Pick an icon for each game and each rank tier. Game icons appear on tournament cards.

### 🐛 Fixed

#### Draws work in ranked

Seasons that allow draws accept them when entering a match, count them in ratings and show them on profiles.

#### The rating recap shows what actually changed

When past matches are recalculated, the recap shows the difference instead of repeating points you already saw, and groups all the changes on one card.

- No more recap of old matches after a recalculation
- The leaderboard refreshes after you save a match

title: Match formats beyond 1v1
summary: Duels or matches of up to eight sides — solo, fixed rosters, or teams assembled per match, with configurable team sizes.
order: 3

---

A match opposes two sides holding the same number of players each — or, when the organiser
allows it, up to eight sides ranked by finishing order: a 1v1v1 kart race, a 2v2v2 pétanque
game. Teams are grouped per match (flex) or carried across the whole event (static), with a
minimum and maximum team size you set — so 1v1 chess, 2v2 foosball and 5v5 five-a-side all
fit.

---
type: fixed
title: A match on the last day of a tournament is no longer shown as an invalid date
---
When you picked a time on a tournament's or season's last day while creating a match, the
date field turned red as if it were out of range. The whole last day is now accepted. A date
that really is outside the tournament now says which dates you can pick, and you can only
move on once it is fixed.

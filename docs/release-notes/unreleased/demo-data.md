title: Try Skol Arena with ready-made demo data
audience: self-hosters

Start a new instance with `INIT_DEMO_DATA=true` and it comes filled with a pool club that has been playing for a few months: sixteen players, leagues, a ranked season, a cup bracket, teams and close to 300 matches — some waiting for your confirmation, one disputed. Sign in as the admin or as any player to see every screen in use. A ready-made `docker-compose.demo.yml` is in the repository; see [Demo data](/docs/deployment#demo-data).

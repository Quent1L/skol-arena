audience: self-hosters

Start a new instance with `INIT_DEMO_DATA=true` to get a pool club a few months in: sixteen players, leagues, a ranked season, a cup, teams and about 400 matches, some pending, one disputed, votes already cast. The login page shows the admin's credentials with a one-click sign-in. A `docker-compose.demo.yml` is ready in the repository; see [Demo data](/docs/deployment#demo-data).

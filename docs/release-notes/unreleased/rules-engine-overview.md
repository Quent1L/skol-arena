---
type: new
title: See how all your automatic rules perform on one screen
audience: super-admins
---
A new statistics screen, opened from the rules list, shows every message and badge rule at a
glance: how often they were triggered, how many messages players actually read, and which
active rules have never been triggered at all.

Below it, a list shows the latest rules triggered — who got which message or badge,
and for which match — and can be narrowed to one rule, one kind of rule or one outcome.
